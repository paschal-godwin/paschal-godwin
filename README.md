# Hi, I'm Paschal 👋

**Radiographer & clinical RAG engineer.** I build clinical decision-support systems with one non-negotiable rule: **the AI doesn't make the decision.** Deterministic logic handles anything high-stakes, retrieval is used only to *cite the evidence* behind a call, and the system reports its own confidence and **defers when it isn't sure enough to be trusted.**

Abstain-first, evaluation-driven, built for the messy real department — not the clean demo.

### 🧩 What I'm building
- **[Radiology Protocol & Risk Decision Support](https://github.com/paschal-godwin/Radiology-Protocol-and-Risk-Decision-Support-System)** — assesses renal, contrast-reaction, pregnancy and missing-info risk for a patient case. Deterministic rules make the call; RAG supplies the guideline evidence; layered confidence scoring decides when to defer.
- **[deterministic-policy-decision-agent](https://github.com/paschal-godwin/deterministic-policy-decision-agent)** — compliance-grade RAG with abstain-first gating, deterministic confidence scoring, evidence citation, and regression-tested evaluation.
- **[rag-debugger](https://github.com/paschal-godwin/rag-debugger)** — a RAG debugging & evaluation tool with retrieval inspection and regression-style comparison.
- **[student-agent](https://github.com/paschal-godwin/student-agent)** — a RAG study assistant (LangChain + FAISS) that summarizes textbooks, generates flashcards, and answers questions with citations.
